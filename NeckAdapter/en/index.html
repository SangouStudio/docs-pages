Installation

1. Back up your project

  • Take a backup of the project you are going to work in.

2. Prepare the project

  1. Import the required assets.
  2. Import the unitypackage "NeckAdapter_NV_Main_XXX". XXX is the version number.
  3. Import the unitypackage "NeckAdapter_NV_(avatar name)".

3. Disable the avatar parts you will not use

  1. Select the avatar's head, hair and so on.
  2. Turn off the checkbox in the Inspector.
  3. Set Tag to EditorOnly. * EditorOnly stops them being uploaded, so unnecessary textures are not included in the avatar.

4. [ IMPORTANT ] Set up lip sync

Note: if you skip this, your avatar can no longer be built.

  1. Select the avatar's root object.
  2. In VRC Avatar Descriptor / LipSync / Mode, choose Viseme Parameter Only from the dropdown.

5. Stop the neck poking through

  1. If the folder SangouStudio/Argments/NeckAdapter/for_NovaVultus/Variants/(avatar name) contains a texture named "t_Mask_Body_(avatar name)", that avatar needs this setting. If there is no such texture, go on to "Place the Prefab". Example: Milltina.
  1. Select the object that holds the body's skinned mesh. Example: Body_base
  2. In the Inspector, use Add Component to add AAO Remove Mesh By Mask.
  1. Turn on "Apply to material slot 0".
  2. Assign "t_Mask_Body_(avatar name)" to "Mask Texture". Example: Milltina.

6. Place the Prefab

  • Place the Prefab directly under the avatar. It is named "NeckAdapter_NV_(avatar name)" and sits in SangouStudio/Argments/NeckAdapter/for_NovaVultus/Variants/(avatar name).

7. Customise NovaVultus

  1. NovaVultus's Prefab "Mecha_Head_Set" is placed automatically inside the object "PUT_MechaHead_HERE" within the Prefab you just placed.
  2. Inside "Mecha_Head_Set", select the objects you want to use.
  3. Turn on the checkbox in the Inspector.
  4. Set Tag to Untagged.
  1. Check that the objects you are not using have their Inspector checkbox off and their Tag set to EditorOnly.

8. Copy the NovaVultus material settings

  1. Select "m_NeckAdapter_NV_Sample_LT" in Assets/SangouStudio/Augments/NeckAdapter/for_NovaVultus/Materials.
  2. Open the dropdown from the gear icon to the right of the emission settings in the Inspector and click "Copy".
  1. Select the material of the NovaVultus body (the mechanical head base), such as SpeQ_MechaHead_Base_A.
  2. Open the dropdown from the gear icon to the right of the emission settings and click "Paste (including textures)".
  3. Copy and paste the AudioLink settings in the same way.

9. Test your avatar

  1. Always check the behaviour with Build Type "Build & Test Your Avatar" before you upload.
  2. If the error below appears in the VRChat SDK tab and the avatar cannot be built, run Auto Fix.

Operating it in VRChat

1. Turning the voice-driven blinking on and off

  • Switch it on and off from ExMenu, NeckAdapter/Vox Pulse.

2. Turning AudioLink on and off

  • Switch it on and off from ExMenu, NeckAdapter/AudioLink.
