ExMenuとパラメーター

VR169のExMenuと、そこで使用しているパラメーターについて記載します。

操作

基本

起動

VR169の起動と終了を制御する。

  • VR169_Power
  • Bool
    • 0 終了
    • 1 起動

本体

モデル表示

VR169本体の3Dモデルの表示および非表示を制御する。

  • VR169_ModelVisible
  • Bool
    • 0 非表示
    • 1 表示

インターフェース展開

レバー等の操作UIを強制的に展開または格納する。

  • VR169_Wakeup
  • Bool
    • 0 格納
    • 1 展開

レボルビング

ディスプレイを回転させ、画面の向き（横位置／縦位置）を制御する。

  • VR169_Revolving
  • Bool
    • 0 横位置（ランドスケープ）
    • 1 縦位置（ポートレート）

フォーカスポイント

フォーカスロック

ピントの距離をその位置で固定する。

  • VR169_FocusLock
  • Bool
    • 0 無効
    • 1 有効

疑似視線制御AF

頭の向きに合わせてフォーカスポイントを追従させる『疑似視線制御AF』の有効および無効を制御する。

  • VR169_FaceAim
  • Bool
    • 0 無効
    • 1 有効

中央リセット

フォーカスポイントを即座に画面中央へ復帰させる。

  • VR169_FocusPoint_CenterReset
  • Bool
    • 0 待機
    • 1 実行

中央固定

フォーカスポイントを画面中央に固定する。中央固定は疑似視線AFよりも優先して適用される。

  • VR169_FocusPoint_CenterLock
  • Bool
    • 0 無効
    • 1 有効

カメラ配置モード

再配置倍率

カメラ配置モード『再配置』における移動量（倍率）を2段階で切り替える。LowとHighの具体的な倍率は再配置倍率モード設定に依存する。

  • VR169_RepositionScale
  • Int
    • 0 Low
    • 1 High

VR169 Companion

シャッター

VR169 Companionにシャッターを切らせる。

＊シャッターだけをExMenuで操作したい場合の為に同名のサブメニューに格納されています。

  • VR169_Shutter
  • Bool
    • 0 待機
    • 1 実行

OSC Check

VR169 Companionとの通信をモニタリングする。数秒おきにオンになっていればアプリと接続できています。アプリ側で接続が切れた場合、これを実行することで接続が回復する場合があります。

  • VR169_Heartbeat
  • Bool
    • 0 待機
    • 1 実行

設定

本体

カメラユニットの自動非表示

一部のカメラ配置モードでカメラユニットを非表示にする。

  • VR169_Setting_CameraUnit_AutoHide
  • Bool
    • 0 無効
    • 1 有効

エミッション輝度設定

スイッチやレバーの発光部分の明るさを設定する。

  • VR169_Setting_Emission_Intensity
  • Float
    • 0 暗い
    • 1 明るい

インターフェース自動展開

フリーハンドがカメラ付近にあり、かつ視線がカメラに向いている場合、レバー等の操作UIを自動的に展開（表示）するかを設定する。

  • VR169_Setting_Wakeup_AutoMode
  • Bool
    • 0 無効
    • 1 有効

レボルビング / 自動水平連動

カメラの自動水平出し機能に連動して、ディスプレイを自動的に回転（レボルビング）させるかを設定する。

  • VR169_Setting_Revolving_AutoMode
  • Bool
    • 0 無効
    • 1 有効

フォーカス

ピーキング / 絞り連動

いずれかのレバーモードが絞りのときのフォーカスピーキング動作を設定する。

  • VR169_Setting_FocusPeaking_Aperture
  • Int
    • 0 無効
    • 1 有効
    • 2 自動 （レバーを握るとフォーカスピーキングがオンになり、離すとオフになる）

ピーキング / MF連動

いずれかのレバーモードがマニュアルフォーカスの時のフォーカスピーキング動作を設定する。この設定は『絞り連動フォーカスピーキング』よりも優先して適用される。

  • VR169_Setting_FocusPeaking_MF
  • Int
    • 0 無効
    • 1 有効
    • 2 自動 （レバーを握るとフォーカスピーキングがオンになり、離すとオフになる）

連動切替 / 手持ち連動一点AF

カメラ配置モードが『手持ち』になったときに、自動的にフォーカスモードを『一点AF』に切り替える。

  • VR169_Setting_FocusSync_Hand
  • Bool
    • 0 無効
    • 1 有効

疑似視線制御AF / 自動補正

疑似視線制御AFにおける自動角度補正の有効化および、その補正量を設定する。

  • VR169_Setting_FaceAim_AutoStrength
  • Int
    • 0 無効
    • 1 Low
    • 2 Mid
    • 3 High

疑似視線制御AF / 手動角度補正

疑似視線AFのターゲット位置に対して、手動で角度のオフセットを補正する。

  • VR169_Setting_FaceAim_ManualAngle
  • Float 0-1
    • 0 マイナス補正
    • 0.5 補正なし
    • 1 プラス補正

レバー

割り当て / ズーム、絞り

ズームと絞りをいずれのレバーに割り当てるかを設定する。

  • VR169_Setting_LeverSelector_Main
  • Int
    • 1 レバー1『ズーム』、レバー2『絞り』
    • 2 レバー1『絞り』、レバー2『ズーム』

割り当て/ マニュアルフォーカス

フォーカスモードが『マニュアル』のときに、いずれのレバーをマニュアルフォーカスに使用するかを設定する。

  • VR169_Setting_LeverSelector_MF
  • Int
    • 1 レバー1
    • 2 レバー2

割り当て / 自撮りカメラ距離

カメラ配置モードが『自撮り』のときに、いずれのレバーをカメラ距離操作に使用するかを設定する。

  • VR169_Setting_LeverSelector_SelfieDistance
  • Int
    • 1 レバー1
    • 2 レバー2

クイックコール / レバー１

レバー1を握った状態でVRコントローラーのトリガーを入力した際に、呼び出されるクイックコールを設定する。 本機能を利用するには、予めVirtualLens2側での設定が必要。VirtualLens2の『QuickCall』設定リストにおいて、一番上がクイックコール1、その1つ下がクイックコール2となる。

  • VR169_Setting_Lever01_QuickCall
  • Int
    • 0 無効
    • 1 クイックコール1
    • 2 クイックコール2
    • 3 クイックコール3
    • 4 クイックコール4

クイックコール / レバー２

レバー2を握った状態でVRコントローラーのトリガーを入力した際に、呼び出されるクイックコールを設定する。 本機能を利用するには、予めVirtualLens2側での設定が必要。VirtualLens2の『QuickCall』設定リストにおいて、一番上がクイックコール1、その1つ下がクイックコール2となる。

  • VR169_Setting_Lever02_QuickCall
  • Int
    • 0 無効
    • 1 クイックコール1
    • 2 クイックコール2
    • 3 クイックコール3
    • 4 クイックコール4

ハンドサイン

スイッチ用ジェスチャー設定

フリーハンドにおいて、スイッチを起動する方式とジェスチャーを設定する。

  • VR169_Setting_FreeHand_Mode
  • Int
    • 2 ハンドオープン（HandOpen）
    • 3 フィンガーポイント（FingerPoint）
    • 4 ビクトリー（Victory）
    • 5 ロックンロール（RockNRoll）
    • 6 ハンドガン（HandGun）
    • 100 ダイレクトモード（開発中）

カメラハンド操作モード設定

カメラハンドにおいてシャッター操作やAF駆動を行う際の方式（モード）を設定する。

  • VR169_Setting_CamHand_Mode
  • Int
    • 0 無効
    • 1 トリガーモード
    • 2 クイックモード
    • 3 グリップモード
    • 100 ダイレクトモード（開発中）

カメラハンドフォーカス操作設定

カメラハンド操作モード設定で指定されたジェスチャーによるフォーカスロック（FL）の挙動を設定する。

  • VR169_Setting_CamHand_FocusLockMode
  • Int
    • 0 無効（FL操作を行わない）
    • 1 トグル（FL有効と無効が入力されるたびに切り替わる）
    • 2 AF駆動（親指AFのような動作。常にFLを有効にしジェスチャー中のみFLを解除してAFを駆動させる）

カメラ配置モード

再配置倍率モード設定

カメラ配置モード『再配置』における、Low / Highの倍率の組み合わせ（モード）を設定する。

  • VR169_Setting_RepositionScale_Mode
  • Int
    • 1 モード1（Low：1x、High：10x）
    • 2 モード2（Low：1x、High：30x）
    • 3 モード3（Low：3x、High：10x）
    • 4 モード4（Low：3x、High：30x）

VR169 Companion

連携起動

VR169 Companionによるカメラ連携自動起動の有効と無効を切り替えます。

  • VR169_CamLink
  • Bool
    • 0 無効
    • 1 有効

その他パラメーター

内部で使用しているパラメーターを一部記載します。これらのパラメーターはExMenuから直接操作するものではありません。

フォーカスモード

現在のフォーカスモードの状態を保持・制御する。

  • VR169_FocusMode
  • Int
    • 0 一点AF
    • 1 顔検出AF
    • 2 自撮りAF
    • 3 マニュアルフォーカス

カメラ配置モード

現在のカメラ配置モードの状態を保持・制御する。

  • VR169_PlacementMode
  • Int
    • 0 手持ちモード（カメラがアバターの手に追従している状態）
    • 1 空間固定モード（カメラをワールドに固定している状態）
    • 2 自撮りモード（自撮り用カメラを使用している状態）
    • 3 再配置モード（カメラを再配置している状態）
    • 4 ドローンモード（カメラをドローンとして操作している状態）

カメラ配置モード準備状態

カメラ配置モード切り替え時の特殊な準備（オフセット調整など）状態を示す。

  • VR169_PlacementPrepState
  • Int
    • 0 準備状態ではない
    • 3 再配置準備状態（カメラの再配置モードのオフセットを調整している状態）
    • 4 ドローン準備状態（ドローンモードで操作する手を調整している状態）

自動水平

自動水平機能の状態を保持・制御する。

  • VR169_AutoLeveler
  • Int
    • 0 無効
    • 1 水平（横位置）
    • 2 垂直（縦位置）
