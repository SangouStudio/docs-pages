Updating

How to replace an installed VR169 with a newer version.

If you are installing for the first time, you can skip this chapter. Go to "Installing on your avatar".

Every time

  • Back up your Unity project before you begin.
  • Test-build the avatar and check that it works before you upload it.

Steps for each version

These are the steps for moving from the version you have to a newer one. For any combination not listed below, importing over the top is all you need to do.

**\* Where a step asks you to delete a folder, always delete it from within Unity's Project window.** Do not delete directly in Explorer or a similar file manager.

From 1.1.0 to 1.2.0

  1. Back up your Unity project.
  2. In Unity's Project window, delete the following folder.
    • Assets/SangouStudio/CameraController/VR169
  3. Import VR169_1.2.0.unitypackage into the project.

If it does not work

If the references on the avatar have come loose, please go to Place VR169 and VirtualLens2 on the avatar in "Installing on your avatar" and set it up on the avatar again.
