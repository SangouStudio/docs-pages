The ExMenu and parameters

This chapter covers the VR169 ExMenu and the parameters it uses.

Menu map

The VR169 ExMenu is laid out as below. The order may differ.

  • VR169
    • On / Off
    • Model display
    • Emission brightness
    • Operation
      • Deploy levers
      • Revolving
      • Focus point
        • Focus lock
        • Pseudo gaze-controlled AF
        • Reset
        • Center lock
      • Reposition scale
        • Low
        • High
      • VR169 Companion
        • Shutter function
    • Settings
      • Body
        • Auto-hide the camera unit
        • Auto-deploy the levers
        • Automatic revolving
      • Gestures
        • Shutter
        • Focus lock
        • Switch
      • Focus
        • Peaking
          • Linked to aperture
          • Linked to MF
        • Linked to camera placement mode
          • Hand > Point AF
        • Pseudo gaze-controlled AF
          • Manual angle compensation (ManComp)
          • Automatic compensation (AutoComp): Off
          • Automatic compensation (AutoComp): Low
          • Automatic compensation (AutoComp): Mid
          • Automatic compensation (AutoComp): High
      • Levers
        • Assignment
          • Zoom and aperture
          • Manual focus
          • Selfie camera distance
        • QuickCall

        • Linked start

Operation

Basic

Power

Controls starting and stopping VR169.

  • VR169_Power
  • Bool
    • 0 stopped
    • 1 started

Body

Model display

Controls whether the VR169 3D model is shown or hidden.

  • VR169_ModelVisible
  • Bool
    • 0 hidden
    • 1 shown

Interface deployment

Forcibly deploys or stows the operating UI, such as the levers.

  • VR169_Wakeup
  • Bool
    • 0 stowed
    • 1 deployed

Revolving

Rotates the display, controlling the screen orientation (landscape / portrait).

  • VR169_Revolving
  • Bool
    • 0 landscape
    • 1 portrait

Focus point

Focus lock

Fixes the focus distance at its current position.

  • VR169_FocusLock
  • Bool
    • 0 disabled
    • 1 enabled

Pseudo gaze-controlled AF

Controls whether "pseudo gaze-controlled AF", which makes the focus point follow the direction of your head, is enabled.

  • VR169_FaceAim
  • Bool
    • 0 disabled
    • 1 enabled

Center reset

Returns the focus point to the centre of the screen immediately.

  • VR169_FocusPoint_CenterReset
  • Bool
    • 0 idle
    • 1 run

Center lock

Fixes the focus point at the centre of the screen. Center lock takes precedence over pseudo gaze-controlled AF.

  • VR169_FocusPoint_CenterLock
  • Bool
    • 0 disabled
    • 1 enabled

Camera placement mode

Reposition ratio

Switches the amount of movement (the ratio) in the "Reposition" camera placement mode between two steps. The actual ratios for Low and High depend on the reposition ratio mode setting.

  • VR169_RepositionScale
  • Int
    • 0 Low
    • 1 High

VR169 Companion

Shutter

Makes VR169 Companion release the shutter.

\* It is kept in a submenu of the same name, for when you want to operate only the shutter from the ExMenu.

  • VR169_Shutter
  • Bool
    • 0 idle
    • 1 run

OSC Check

Monitors communication with VR169 Companion. If it turns on every few seconds, the application is connected. If the connection has dropped on the application side, running this sometimes restores it.

  • VR169_Heartbeat
  • Bool
    • 0 idle
    • 1 run

Settings

Body

Auto-hide the camera unit

Hides the camera unit in some camera placement modes.

  • VR169_Setting_CameraUnit_AutoHide
  • Bool
    • 0 disabled
    • 1 enabled

Emission brightness

Sets the brightness of the glowing parts of the switches and levers.

  • VR169_Setting_Emission_Intensity
  • Float
    • 0 dark
    • 1 bright

Automatic interface deployment

Sets whether the operating UI, such as the levers, is deployed (shown) automatically when your free hand is near the camera and you are looking at the camera.

  • VR169_Setting_Wakeup_AutoMode
  • Bool
    • 0 disabled
    • 1 enabled

Revolving / linked to auto leveler

Sets whether the display rotates automatically (revolving) in step with the camera's auto-levelling function.

  • VR169_Setting_Revolving_AutoMode
  • Bool
    • 0 disabled
    • 1 enabled

Focus

Peaking / linked to aperture

Sets how focus peaking behaves when either lever mode is aperture.

  • VR169_Setting_FocusPeaking_Aperture
  • Int
    • 0 disabled
    • 1 enabled
    • 2 automatic (focus peaking turns on when you grip the lever and off when you let go)

Peaking / linked to MF

Sets how focus peaking behaves when either lever mode is manual focus. This setting takes precedence over "focus peaking linked to aperture".

  • VR169_Setting_FocusPeaking_MF
  • Int
    • 0 disabled
    • 1 enabled
    • 2 automatic (focus peaking turns on when you grip the lever and off when you let go)

Linked switching / Point AF linked to Hand

Switches the focus mode to "Point AF" automatically when the camera placement mode becomes "Hand".

  • VR169_Setting_FocusSync_Hand
  • Bool
    • 0 disabled
    • 1 enabled

Pseudo gaze-controlled AF / automatic compensation

Enables automatic angle compensation for pseudo gaze-controlled AF and sets how much it compensates.

  • VR169_Setting_FaceAim_AutoStrength
  • Int
    • 0 disabled
    • 1 Low
    • 2 Mid
    • 3 High

Pseudo gaze-controlled AF / manual angle compensation

Applies a manual angle offset to the target position of pseudo gaze AF.

  • VR169_Setting_FaceAim_ManualAngle
  • Float 0-1
    • 0 negative compensation
    • 0.5 no compensation
    • 1 positive compensation

Levers

Assignment / zoom and aperture

Sets which lever zoom and aperture are assigned to.

  • VR169_Setting_LeverSelector_Main
  • Int
    • 1 lever 1 "zoom", lever 2 "aperture"
    • 2 lever 1 "aperture", lever 2 "zoom"

Assignment / manual focus

Sets which lever is used for manual focus when the focus mode is "Manual".

  • VR169_Setting_LeverSelector_MF
  • Int
    • 1 lever 1
    • 2 lever 2

Assignment / selfie camera distance

Sets which lever is used to control the camera distance when the camera placement mode is "Selfie".

  • VR169_Setting_LeverSelector_SelfieDistance
  • Int
    • 1 lever 1
    • 2 lever 2

QuickCall / lever 1

Sets the QuickCall that is called when you pull the VR controller trigger while gripping lever 1. To use this you must first configure it in VirtualLens2. In the VirtualLens2 "QuickCall" settings list, the top entry is QuickCall 1 and the one below it is QuickCall 2.

  • VR169_Setting_Lever01_QuickCall
  • Int
    • 0 disabled
    • 1 QuickCall 1
    • 2 QuickCall 2
    • 3 QuickCall 3
    • 4 QuickCall 4

QuickCall / lever 2

Sets the QuickCall that is called when you pull the VR controller trigger while gripping lever 2. To use this you must first configure it in VirtualLens2. In the VirtualLens2 "QuickCall" settings list, the top entry is QuickCall 1 and the one below it is QuickCall 2.

  • VR169_Setting_Lever02_QuickCall
  • Int
    • 0 disabled
    • 1 QuickCall 1
    • 2 QuickCall 2
    • 3 QuickCall 3
    • 4 QuickCall 4

Hand signs

Switch gesture

Sets the method and gesture used on the free hand to activate a switch.

  • VR169_Setting_FreeHand_Mode
  • Int
    • 2 HandOpen
    • 3 FingerPoint
    • 4 Victory
    • 5 RockNRoll
    • 6 HandGun
    • 100 direct mode (in development)

Camera hand operation mode

Sets the method (mode) used on the camera hand for the shutter operation and AF drive.

  • VR169_Setting_CamHand_Mode
  • Int
    • 0 disabled
    • 1 trigger mode
    • 2 quick mode
    • 3 grip mode
    • 100 direct mode (in development)

Camera hand focus operation

Sets how focus lock (FL) behaves with the gesture specified in the camera hand operation mode.

  • VR169_Setting_CamHand_FocusLockMode
  • Int
    • 0 disabled (no FL operation)
    • 1 toggle (FL alternates between enabled and disabled on each input)
    • 2 AF drive (behaves like back-button AF: FL is always on, and is released only while the gesture is held, so autofocus runs)

Camera placement mode

Reposition ratio mode

Sets the combination (mode) of Low and High ratios used in the "Reposition" camera placement mode.

  • VR169_Setting_RepositionScale_Mode
  • Int
    • 1 mode 1 (Low: 1x, High: 10x)
    • 2 mode 2 (Low: 1x, High: 30x)
    • 3 mode 3 (Low: 3x, High: 10x)
    • 4 mode 4 (Low: 3x, High: 30x)

VR169 Companion

Linked start

Switches the automatic camera-linked start by VR169 Companion on and off.

  • VR169_CamLink
  • Bool
    • 0 disabled
    • 1 enabled

Other parameters

Some of the parameters used internally are listed here. These are not meant to be operated directly from the ExMenu.

Focus mode

Holds and controls the current focus mode.

  • VR169_FocusMode
  • Int
    • 0 Point AF
    • 1 Face AF
    • 2 Selfie AF
    • 3 manual focus

Camera placement mode

Holds and controls the current camera placement mode.

  • VR169_PlacementMode
  • Int
    • 0 hand mode (the camera follows the avatar's hand)
    • 1 world-fixed mode (the camera is fixed in the world)
    • 2 selfie mode (the selfie camera is in use)
    • 3 reposition mode (the camera is being repositioned)
    • 4 drone mode (the camera is operated as a drone)

Camera placement preparation state

Indicates a special preparation state (such as adjusting an offset) while switching the camera placement mode.

  • VR169_PlacementPrepState
  • Int
    • 0 not in a preparation state
    • 3 reposition ready (adjusting the offset for the camera's reposition mode)
    • 4 drone ready (adjusting the hand used to operate drone mode)

Auto leveler

Holds and controls the state of the auto-levelling function.

  • VR169_AutoLeveler
  • Int
    • 0 disabled
    • 1 landscape
    • 2 portrait
